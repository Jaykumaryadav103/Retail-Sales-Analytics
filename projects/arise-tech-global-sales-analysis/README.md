# Online Store Sales Analysis

This is a small practice project for an entry-level data analyst portfolio. It looks at a year of online store orders using Excel and SQL.

The data is made up for practice. It is not from a real company. No AI or machine-learning model is used in the analysis.

## Files

- `data/orders_sample.csv` — 300 sample orders
- `excel/AriseTech_Retail_Sales_Analysis.xlsx` — dashboard, summaries, and order details
- `sql/analysis_queries.sql` — queries for SQLite
- `insights.md` — a few observations and questions to explore

## What I looked at

- How sales changed by month
- Which product categories and cities had the most sales
- How many orders were delivered, returned, or cancelled
- The return rate across the sample orders

Sales are counted only for delivered orders, after discounts. Returned and cancelled orders have zero sales in this calculation.

## Try it yourself

Open the Excel file and start on the Dashboard tab. The Orders tab has the individual records. You can also load the CSV into SQLite and run the queries in `sql/analysis_queries.sql`.

Before adding this project to your portfolio, make sure you can explain how the sales and return-rate figures are calculated. You can also change one of the questions, add your own chart, and write down what you found.
